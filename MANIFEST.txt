Code change:
  def predict_with_uncertainty(self, X, num_samples=50):
      # Forward pass 50 times with dropout ON
      predictions = []
      for _ in range(num_samples):
          pred = self.model(X, training=True)
          predictions.append(pred.numpy())
      mean = np.mean(predictions, axis=0)
      std = np.std(predictions, axis=0)
      confidence = 1.0 / (1.0 + std / mean)
      return mean, std, confidence

💡 DECISION MAKING GUIDE
===============================================================================

For Each Product Prediction:

IF confidence < 0.5:
  → Use fallback strategy (exponential smoothing)
  → Set confidence = 0.5
  
IF ood_score > 0.6:
  → Likely new product
  → Use fallback strategy
  → Set confidence = 0.5
  
IF confidence > 0.7 AND ood_score < 0.3:
  → Known product, high confidence
  → Use LSTM prediction
  → Set confidence = (1 - ood_score)

OTHERWISE:
  → Medium confidence situation
  → Blend LSTM and fallback
  → Reduced confidence
